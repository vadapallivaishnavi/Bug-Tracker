## Step 1 — Proxmox API Token

You need a Proxmox API token (not your root password).

1. Log into the Proxmox web UI → **Datacenter → Permissions → API Tokens**
2. Click **Add**
3. Fill in:
   - User: `root@pam` (or a dedicated user)
   - Token ID: `vmportal`
   - Uncheck "Privilege Separation" so it inherits root permissions
4. Copy the token value shown — it is only displayed once.
5. Assign permissions:
   - Go to **Datacenter → Permissions → Add → API Token Permission**
   - Path: `/`
   - Token: `root@pam!vmportal`
   - Role: `Administrator`

Your `.env` values will be:
```
PROXMOX_HOST=<your Proxmox IP or hostname>
PROXMOX_USER=root@pam
PROXMOX_TOKEN_NAME=vmportal
PROXMOX_TOKEN_VALUE=<the token value you copied>
PROXMOX_NODE=pve           # run: pvesh get /nodes — use the name shown
```

## Step 2 — PostgreSQL Database

```bash
# Log in as postgres superuser
sudo -u postgres psql

# Create the database and a dedicated user
CREATE USER vmportal_user WITH PASSWORD 'choose-a-strong-password';
CREATE DATABASE vmportal OWNER vmportal_user;
GRANT ALL PRIVILEGES ON DATABASE vmportal TO vmportal_user;
\q
```

Your `.env` value:
```
DATABASE_URL=postgresql://vmportal_user:choose-a-strong-password@localhost/vmportal
```

If PostgreSQL is on a different host/port:
```
DATABASE_URL=postgresql://vmportal_user:password@192.168.1.50:5432/vmportal
```

## Step 3 — Microsoft Teams Webhook (optional)

1. In Teams, open the channel you want alerts in
2. Click **···** → **Connectors** → **Incoming Webhook** → **Configure**
3. Give it a name (e.g. "VM Portal Alerts") and click **Create**
4. Copy the webhook URL

Your `.env` value:
```
TEAMS_WEBHOOK_URL=https://your-org.webhook.office.com/webhookb2/xxxxxxxx.../IncomingWebhook/...
```

Leave it blank to disable Teams notifications:
```
TEAMS_WEBHOOK_URL=
```

---

## Step 4 — Slack Webhook (optional)

1. Go to https://api.slack.com/apps → **Create New App** → **From scratch**
2. Add the **Incoming Webhooks** feature and activate it
3. Click **Add New Webhook to Workspace**, select your channel
4. Copy the webhook URL

Your `.env` value:
```
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T.../B.../xxxxxx
```

## Step 5 — Email / SMTP (optional)

For Gmail:
1. Enable 2-Factor Authentication on your Google account
2. Go to **myaccount.google.com → Security → App passwords**
3. Generate a password for "Mail" / "Other (custom name)"
4. Use that 16-character password as `SMTP_PASSWORD`

Your `.env` values:
```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@gmail.com
SMTP_PASSWORD=abcd efgh ijkl mnop    # the 16-char app password (spaces OK)
SMTP_FROM=VM Portal <your@gmail.com>
```

For Office 365:
```
SMTP_HOST=smtp.office365.com
SMTP_PORT=587
SMTP_USER=your@company.com
SMTP_PASSWORD=your-password
```

## Step 7 — Backend Installation & Run

```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate it
# Linux/macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run database migrations (creates all tables automatically)
# Tables are created on first startup via SQLAlchemy

# Start the server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

The API will be live at:
- `http://localhost:8000` — health check
- `http://localhost:8000/docs` — interactive Swagger UI
- `http://localhost:8000/redoc` — ReDoc documentation

## Step 8 — Frontend Installation & Run

The frontend is a single React component (`VMPortal.jsx`). You can use it with any React setup.

### Option A — Existing React project (recommended)

```bash
# Install into your project
npm install react react-dom

# Copy VMPortal.jsx into your src/ folder
# Then in App.js:
import VMPortal from "./VMPortal";
export default function App() { return <VMPortal />; }

# Update the API_BASE constant in VMPortal.jsx:
# const API_BASE = "http://YOUR_SERVER_IP:8000";

npm start
```

### Option B — Fresh Create React App

```bash
npx create-react-app vm-portal
cd vm-portal
cp /path/to/VMPortal.jsx src/VMPortal.jsx

# Edit src/App.js:
# import VMPortal from "./VMPortal";
# export default function App() { return <VMPortal />; }

npm start
```

### Option C — Vite (faster, recommended for new projects)

```bash
npm create vite@latest vm-portal -- --template react
cd vm-portal
npm install
cp /path/to/VMPortal.jsx src/VMPortal.jsx

# Edit src/main.jsx to import VMPortal instead of App
npm run dev
```

## Environment Variable Reference

| Variable | Required | Description |
|---|---|---|
| `PROXMOX_HOST` | ✅ | IP or hostname of your Proxmox server |
| `PROXMOX_USER` | ✅ | Proxmox user (e.g. `root@pam`) |
| `PROXMOX_TOKEN_NAME` | ✅ | API token name (e.g. `vmportal`) |
| `PROXMOX_TOKEN_VALUE` | ✅ | API token secret value |
| `PROXMOX_NODE` | ✅ | Proxmox node name (run `pvesh get /nodes` to check) |
| `DATABASE_URL` | ✅ | PostgreSQL connection string |
| `TEAMS_WEBHOOK_URL` | ⬜ | Teams incoming webhook URL |
| `SLACK_WEBHOOK_URL` | ⬜ | Slack incoming webhook URL |
| `SMTP_HOST` | ⬜ | SMTP server hostname |
| `SMTP_PORT` | ⬜ | SMTP port (587 for TLS, 465 for SSL) |
| `SMTP_USER` | ⬜ | SMTP login email |
| `SMTP_PASSWORD` | ⬜ | SMTP password or app password |
| `SMTP_FROM` | ⬜ | From address shown in emails |

✅ = required for backend to start   ⬜ = optional, feature disabled if blank

## Running in Production

```bash
# Backend — use gunicorn instead of uvicorn --reload
pip install gunicorn
gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000

# Frontend — build static files
npm run build
# Serve the build/ folder with nginx or any static host
```

A minimal `systemd` service for the backend:
```ini
# /etc/systemd/system/vmportal.service
[Unit]
Description=VM Booking Portal API
After=network.target postgresql.service

[Service]
User=ubuntu
WorkingDirectory=/opt/vm-booking-portal/backend
EnvironmentFile=/opt/vm-booking-portal/backend/.env
ExecStart=/opt/vm-booking-portal/backend/venv/bin/gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable vmportal
sudo systemctl start vmportal
```
